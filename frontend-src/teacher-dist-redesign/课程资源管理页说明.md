## 1. 这次新增了什么

教师端新增一个「课程资源管理」页面，用来沉淀老师的历史课程资料。
侧边栏位置：**顶层，排在 `课程管理` 分组之后**，没有角标。

**侧边栏和顶栏没有加任何多余东西**：侧栏保持真实的 logo + 菜单结构
（之前误加的「云盘配额条」和「林若鸿 教授」账号卡已删除），
顶栏是应用自己的 `.navbar`（左面包屑、右当前登录人），我们一行都没改。

### 1.1 顺带补齐了侧栏缺失的图标

`学情分析` 和 `课程管理` 原本**没有图标** —— 应用菜单配置里这两项都写的
`icon: 'list'`，但它的图标包里根本没有 `list` 这个名字，所以一直是空白的。
这是应用自身的 bug（配置引用了不存在的图标名）。

`课程资源管理` 原本借用 `i-svg:file`，而 `file` 是**彩色**图标（黄文件夹），
和旁边那些单色线性图标风格不搭。

现在三项都用应用自己的「CSS mask + currentColor」技术补上了单色图标：

| 菜单项 | 图标 | 来源 |
| --- | --- | --- |
| 学情分析 | 图表 | `mdi:chart-box` |
| 课程管理 | 书 | `mdi:book-education` |
| 课程资源管理 | 分层 | `mdi:layers-outline` |

做法：图标图形从离线图标包取，由 `tools/scope_css.py` 生成 CSS 规则
（`.layout__sidebar .i-svg\:cr-xxx`，权重 0,2,0，压过应用的单类名规则）；
接线脚本只替换**确实渲染不出东西**的图标类名，有图的绝不碰。

## 2. 数据全部来自真实接口（重点）

页面**不内置任何演示数据**。三个接口与其它页面同源：

| 接口 | 同源的页面 | 用途 |
| --- | --- | --- |
| `GET /api/v1/course/list` | 课程列表 | 课程主信息 |
| `GET /api/v1/course/content-summary?courseId=N` | 课程管理 | 章节结构、场景、学习路径、知识图谱 |
| `GET /api/teacher-portal/course-generation/jobs` | 课程生成 | 生成任务状态 |
| `GET /api/v1/user/current` | 全局 | 顶栏显示当前登录人 |

归档条目由真实内容推导，规则是：

```
每门课
 ├─ 每章 → 场景（slides / quiz / interactive / code 各 1 条）+ 小节讲义 1 条
 └─ 课程级文档 4 条：课程总览 HTML / 学习路径 / 知识图谱 / 完整课程归档包
```

当前真实数据（登录账号 `uipreview`）下：**1 门课 / 6 章 / 18 节 / 24 个场景 → 34 条归档**。
页面上的每一个数字都由接口返回算出，`tools/check-vault.js` 的 F 段会拿接口原始返回
反推一遍条目数，与页面渲染结果比对，不一致就报错。

**拿不到数据时不会用假数据兜底**：未登录（`code=40100`）、无课程、课程无内容、
接口报错，四种情况分别给出对应的空态/错误提示。

## 7. 过程中修掉的真问题

### 7.1 图标脚本顺序反了 → 运行时偷偷走 CDN

`iconify-icon.min.js` 在**自己的 IIFE 里同步读** `window.IconifyPreload`，
所以预加载脚本必须排在它**前面**。顺序反了的话页面上图标看着正常，
运行时却会去请求 `api.iconify.design`，内网/离线整片丢图标 —— 只看截图发现不了。
已对齐项目里学生端的顺序（`html/pages/index.html` 第 10–11 行）。

### 7.2 预览服务的反代把响应体读了两遍 → 请求永久挂住

```python
# 错：send_header 里 read() 一次，下面又 read() 一次
self.send_header("Content-Length", str(len(resp.read())))
...
payload = resp.read()   # 恒为空
```

发出去的是「有 Content-Length、但零字节」的响应，客户端一直等剩下的字节。
已改为只读一次。

### 7.3 表格操作按钮竖着堆

`.icon-btn` 是 `display: grid`（块级盒），在表格单元格里必然一个占一行。
改成 `display: inline-grid`（在 flex 容器里会被块级化，不影响 dock/弹窗）。

### 7.4 标题重复

场景自带的 `title` 已含章标题，拼标题时又补了一次 `chapter.title`，
变成「第1章 环境搭建与第一个程序 · 环境搭建与第一个程序 · 讲解」。已改为只补章号。

### 7.5 预览弹窗双书名号

`VIEWER.title` 又包了一层《》，而条目名本身已含《》，
显示成「《《从零开始学Python编程》知识图谱》…」。已改为只描述装载状态。

### 7.6 `scrollSemesters` 是未定义的内联 onclick

HTML 里 `onclick="scrollSemesters(-1)"`，但函数在 IIFE 里、没挂到 window，
点一下就 ReferenceError。已改成 id + 事件委托。

### 7.7 `renderAll()` 把 `showFatal()` 的提示语擦掉了

四个空态分支里原本先 `showFatal(...)` 再 `renderAll()`。
`renderAll()` 会重写 `gridWrapper.innerHTML`，顺手把刚写进去的错误文案清掉，
用户永远只看到那句通用的空态 —— 「未登录，无法读取课程数据」这条关键信息根本没露过面。
已把顺序统一改成 `renderAll(); showFatal(...);`，并在注释里写清楚为什么不能反。
这个是 `tools/verify-export.js` 的 B 段断言逼出来的：只截图看不出来。

### 7.8 导出文件名多了一个后缀（`course.json.json`）

条目 `fileName` 本身就以 `.json` 结尾（如 `course.json`），拼下载名时又补了一次。
已加 `/\.json$/i` 判断。同样是 `verify-export.js` 真去读落盘文件才发现的。

### 7.9 统计卡「按归档 JSON 实测」漏掉了小节讲义

6 条小节讲义条目的 `sizeBytes` 写死为 `0`，所以「内容总体量」把它们整个漏掉，
按体积排序时也一律沉底。已改为用该条目真正能导出的那份 JSON 量体积。

## 10. 并入是怎么做的

### 10.1 为什么只能在 dist 层接

`teacher-dist/` 是 **Vite 构建产物**：仓库里没有对应的 Vue 源码，
没有 `vite.config`、没有 `package.json`、一个 `.vue` 文件都没有。
所以没法「加一个页面组件再重新构建」，只能在产物上做运行时接入。

这不是新发明 —— 项目里已经有同样的先例：`teacher-dist/index.html` 里的
`ui-theme.css` 就是靠运行时注入 + `MutationObserver` 打补丁的。

### 10.2 接入点（都是实测出来的，不是猜的）

| 事情 | 结论 |
| --- | --- |
| 路由模式 | hash 路由，`#/dashboard`、`#/course-management/list` |
| 路由实例 | `document.querySelector('#app').__vue_app__.config.globalProperties.$router` |
| 路由出口 | 组件挂载后，`this.$el.parentNode` 就是 `.app-main` |
| 侧栏菜单容器 | `.layout__sidebar ul.el-menu` |
| 菜单项结构 | `div > a > li.el-menu-item`，文字在 `span.menu-title.ml-1` 里，图标是 `div.i-svg:xxx.menu-icon` |

### 10.3 三个关键实现

**① 注册路由 + 挂载页面**

Vue 3 的 `render` 不再把 `h` 当参数传进来（那是 Vue 2 的做法），运行时也拿不到
`createVNode`，所以没法在组件里造 vnode。于是用一个 `render(){return null}` 的组件
（渲染成注释占位节点），在 `mounted` 里往 `this.$el.parentNode`（即 `.app-main`）
`appendChild` 一个宿主 div，把页面挂进去；`beforeUnmount` 里摘掉。

**② 浮层挂到 `document.body`**

批量舱、两个弹窗、toast 都是 `position: fixed`。`.app-main` 是 `overflow: auto`
的滚动容器，路由切换时还会挂 animate.css 的类 —— 只要哪个祖先带上 `transform`，
`fixed` 就会改成相对那个祖先定位。挂到 `body` 下就永远相对视口。

**③ 侧栏菜单项**

结构逐字对齐原生（见上表），并且**把原生节点的 `data-v-*` 属性抄过来**：
应用的组件样式是 `.menu-icon[data-v-d391d0fe] { width:18px }` 这种 SFC scoped 规则，
只命中带该属性的元素；不抄的话图标会掉回 14px，肉眼一看就和别的菜单项不一样。
属性名是**运行时读出来的**，不是硬编码哈希 —— 硬编码的话应用一重新构建就失效。

### 10.4 并入时踩到的四个坑（都是「只有实测才会暴露」型）

**坑 1：`querySelector` 匹配不到元素自己**

`$()` 要在「宿主 + 各浮层」里查节点。浮层容器（`#previewModal` 等）本身就是查找根，
而 `querySelector` 只找**后代** —— 元素永远匹配不到自己。
于是 `$('previewModal')` 恒为 `null`，调用方紧接着在 `.addEventListener` 上炸掉，
报错行号还和真正的原因对不上（报的是下一行）。
修法：查之前先比一次 `r.id === id`。

**坑 2：后代选择器也匹配不到根自身（同一个坑的 CSS 版）**

样式全部收在 `.cr-scope` 下，形式是 `.cr-scope X`。
把 `.cr-scope` 直接加在浮层根上时，`.cr-scope .overlay.is-hidden` 永远不命中 ——
表现是**弹窗和批量舱关不掉、一直浮在页面上**（截图一眼就能看出来）。
修法：每个浮层外面再包一层 `.cr-scope`。

**坑 3：`hashchange` 在 hash 路由下不一定会来**

菜单选中态原本挂在 `hashchange` 上。但我们注入的是原生 `<a href="#/...">`
（真实锚点跳转，会触发），而点应用自己的 router-link 时，
vue-router 的 hash 模式是用 `history.pushState` 改 URL 的 ——
**`pushState` 不触发 `hashchange`**，于是跳走后菜单项一直停在选中态。
修法：改挂 `router.afterEach`。

**坑 4：`mount()` 半途抛异常是静默的**

`bind()` 抛异常时，宿主已经被塞进 DOM、浮层也建好了，但一个子渲染器都没跑 ——
页面上只有一片「--」，而且异常被 Vue 的生命周期钩子吞掉后控制台不一定报。
修法：`mount()` 整体包 `try/catch`，把错误和堆栈直接摊到页面上，别让它静默。

### 10.5 生成脚本（改预览稿后重新生成，别手改正式文件）

```bash
python tools/scope_css.py teacher-dist-redesign/css/resource-vault.css \
                          teacher-dist/css/course-resources.css
python tools/bundle_page.py
```

`scope_css.py` 给所有选择器加 `.cr-scope` 前缀、丢掉复刻外壳的规则；
`bundle_page.py` 把预览的 HTML 片段 + JS 合成可挂载模块。
两个脚本里每一步替换都**断言必须命中** —— 预览稿改了而脚本没跟着改的话，
宁可报错退出，也不要静默产出一个坏掉的包。

## 11. 侧栏图标这一块的三个坑

**坑 1：`mask-image` 的 data URI 里不能出现双引号。**
图标 body 是 `<path fill="currentColor" d="…"/>`，直接塞进 `url("…")` 会把
CSS 字符串提前闭合，整条声明被丢掉 —— 表现是图标位置出现一个**实心方块**
（背景色还在、mask 没了）。必须先把双引号换成单引号（应用的图标规则也是单引号）。

**坑 2：选择器要用 `.layout__sidebar` 打头，不能用 `.el-menu-item`。**
带子菜单的那一项（课程管理）的图标在 `.el-sub-menu__title` 里，
不在 `.el-menu-item` 里。用错前缀的表现是：顶层菜单项有图标，子菜单项没有。

**坑 3：`.cr-scope .is-hidden` 够不着侧栏里的元素。**
角标（后来按需求删掉了）长在应用侧栏上，不在 `.cr-scope` 作用域内，
所以页面那条 `.cr-scope .is-hidden { display:none }` 对它无效 ——
表现是不在本页时侧栏挂着一个**空的蓝色药丸**。
凡是作用在侧栏上的元素，隐藏规则都得单独写在「刻意不加作用域」那一段里。

## 12. 右上角左右箭头「点了没反应」

**反馈**：学期归档区块右上角的左右箭头好像没响应。

**排查**：按钮事件其实绑上了（点击无报错），问题在布局 ——

```
.sem-grid { display: grid; grid-template-columns: repeat(5, minmax(0, 1fr)); }
```

这是**固定 5 列网格**：卡片只会换行，**永远不会横向溢出**。
当前只有 2 个学期，可滚动量 = 0，`scrollBy` 自然什么也不做。
也就是说，这两个箭头**在结构上就不可能有用**，不管有多少学期。

**修法两处**：

1. **让时间轴真的能横向滚**。改成按列排布 + 横向溢出：

   ```css
   .sem-grid {
     display: grid;
     grid-auto-flow: column;
     grid-auto-columns: calc((100% - 40px) / 5);  /* 40px = 4 个 10px 间隙 */
     gap: 10px;
     overflow-x: auto;
     scroll-behavior: smooth;
     scrollbar-width: none;                        /* 滚动条藏起来，靠箭头滚 */
   }
   ```

   每张卡仍占「一行放得下 5 张」的宽度，所以不足 5 张时观感和原来完全一致；
   超过 5 张才溢出，箭头才有意义。媒体查询里的 3 列 / 1 列同理改成
   `grid-auto-columns`。

2. **没东西可滚时把箭头藏起来**，不留死按钮。
   `renderSemesterCards()` 之后同步一次，窗口尺寸变化时再算一次
   （卡片宽度是响应式的，可滚动性会跟着变）。

顺带把滚动步长从写死的 `240px` 改成「一张卡 + 一个间隙」实测值 ——
写死的话宽屏滚不到位、窄屏一次滚过头。

**验证**（已加进 `tools/check-integrated.js` 的 C2 段）：

| 场景 | 可滚动量 | 箭头 | 点击效果 |
| --- | --- | --- | --- |
| 默认（2 个学期） | 0 | `display: none` | —（没有死按钮） |
| 造出 10 张卡 | 1280px | 显示 | 单次滚动 256px（卡片 246 + 间隙 10） |

## 17. 弹窗被侧边栏挡住 / 尺寸不统一 / 按真实类型导出

**① 预览弹窗被左侧边栏挡住（用户反馈）**
教师端侧边栏是 `position:fixed; z-index:999`（宽 260px、满高），而弹窗挂在 `body` 下、
宽度接近整屏 —— 原来的 `z-index:50` 低于 999，弹窗左侧 260px 整条被压住。
`elementFromPoint(60,500)` 命中的是侧边栏滚动容器，实锤。
**修**：把页面级浮层抬到外壳之上、应用自己的浮层档位之下：
`.overlay` 50 → **1500**、`.dock` 40 → **1400**、`.toast-root` 60 → **1600**
（应用 `--el-index-popper = 2000`，所以应用自己的 dialog/popper 仍能盖在我们的弹窗之上）。

**② 排版尺寸不统一（对照参考稿）**
- 弹窗原来是 `max-height:90vh`，**高度随内容忽高忽低**（代码条目矮、大纲条目高，切来切去很跳）。
  参考稿是固定 `h-[92vh]`。已改为 `.modal-xl { width: min(1152px, 94vw); height: 92vh; }`，
  头部工具栏与底部按钮始终在位，中间 body 内部滚动。
- 各预览器补 `max-width` 居中：A4 文档 768px（`max-w-3xl`）、源码编辑器高度 300 → 430px、
  控制台 168 → 220px、目录/正文滚动区改为 `calc(92vh - 260px)` 跟随弹窗高度。

**③ 导出按真实类型给格式（「要 doc 就导出 doc、pdf 就导出 pdf」）**
原来「导出数据」一律给 JSON。现在预览弹窗底部是**格式菜单**，按条目类型给：
| 条目类型 | 可导出 |

| 教学大纲 / 试卷 | Word `.doc` ／ PDF（打印另存） |

## 20. 指标卡右侧图标没居中（贴左偏 9px）

**反馈**：已归档课程 / 归档资料总数 等指标卡右边的图标没对齐，跟色块方框歪出去了。

**量出来的现象**：38×38 的色块里，19×19 的图标**中心比方框中心偏左 9px**（即贴在左边缘），
且方框的**计算 `display` 是 `flex`**——而 CSS 里明明写的是 `display: grid; place-items: center`。

**真因（类名碰撞）**：
```css
.stat span.tone-brand, .stat span.tone-ok, ... { display: inline-flex; ... }   /* 本是给「数字下方小字」的 */
```
而图标是 `<span class="stat-icon tone-brand">` —— **也带 `tone-brand`**，被这条**误命中**。
它的优先级（`.stat` + `.tone-*` + `span` = 0,2,1）高于 `.stat-icon`（0,1,0），
把 `display` 从 `grid` 顶成 `inline-flex`；`place-items` 是 **grid** 属性，flex 下不生效，
水平居中随之失效 → 图标贴左。

**修两处**：
1. 给那条规则加 `:not(.stat-icon)` 排除图标（根因）。
2. 给 `.stat-icon` 补 `justify-content: center` 做 flex 兜底（万一 display 再被改）。

**验证**：偏移 **-9px → 0**、方框 `display` 回到 `grid`；
并加了常驻断言「N 个指标卡图标都居中在色块里（中心偏移 ≤1px 且不外溢）」。

> 排查手段：`CSS.getMatchedStylesForNode` 把命中该节点的规则**按优先级列出来**，
> 一眼看到是 `.cr-scope .stat span.tone-brand` 这条在顶 —— 比反复猜 `place-items` 有没有写快得多。

## 25. 新生成的课程也要六类资料齐全（生成器侧修复）

**需求**：不只是 CS-401 这个演示种子——**「课程生成」新生成的课程，六类资料也必须全部正常**。

**排查出两个根因**：

**① `LocalGenerator` 根本不写 scenes。**
`publish.py._build_scenes()` 是从 `course.json` 顶层的 `scenes` 读的，而当前实际使用的
`LocalGenerator`（`local_generator.py`）只写 `units` + `knowledgeGraph`，**一个场景都不写** ——
所以新生成的课程在资源页上只有「总览 / 知识图谱 / 小节讲义」，其余全空。

**② 生成器的 slides 是 `{title, content}`（content 是 Markdown），不是 `{title, bullets[]}`。**
前端 PPT 预览器只读 `bullets`，于是生成器产出的**每一页课件都显示「（本页要点待补充）」**。

**修**：
1. **`local_generator.py` 补齐六类场景**（与 `llm_generator` 同形，前端预览器直接吃）：
   | 场景 | 素材来源 |
   | --- | --- |
   | `slides` 讲解 | 章节小节（title + body_md） |
   | `quiz` 测验 | 章节测试的 checkpoints → 单选题（无检查点时按小节标题出概念题） |
   | `code` 编程练习 | 章节测试 → `files`（solution.py + checkpoints.json）+ 模拟控制台输出 |
   | `interactive` 交互演示 | 自包含 HTML：按检查点逐条「试运行」 |
   | `handout` 教学大纲 | 小节 → outline/boardNotes + 课程级 courseInfo/schedule（assessment/obeMatrix 是大纲模板的固定章节） |
   | `video` 课堂实录 | 小节 → 章节打点 + 同步字幕 |
2. **`pvPpt` 兼容两种形状**：有 `bullets` 用要点，否则渲染 `content`（Markdown，走内置 mdToHtml）。

**验证**：用接口真的生成一门新课程（`POST /api/teacher-portal/course-generation/jobs`，模板 `cpp-basic`）：
- 接口侧：**5 章 × 6 类 = 30 个场景**，字段齐全（slides 有 content、quiz 有答案、code 有 files/console、
  handout 有 schedule/obeMatrix/courseInfo、video 有 chapters/transcript）；
- 前端侧：该课程在资源页显示 **38 条**，胶囊分布
  「讲解课件 5 / 随堂测验 5 / 编程练习 5 / 交互演示 5 / 教学大纲 5 / 课堂实录 5 / 小节讲义 5 / 课程文档 3」。

**踩坑**：只重启 `ats-comp-backend` **没用** —— 生成任务是 Celery 跑的，
`COURSEGEN_QUEUE = submit_queue`，所以代码要同步到 **`ats-comp-celery-submit-worker`**（及其余 worker）并重启，
或直接重建镜像 + `up -d` 全部服务。
